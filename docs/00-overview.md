# 00 · 总览

## 产品定位

**御坂网络（Misaka Network）** — 浏览器内 P2P 文件传输 Web APP。

- 零注册：节点编号（御坂XXX号）+ 6 位通行码即用
- 端到端：WebRTC P2P，文件本体不经服务器
- 跨设备：PC ↔ 手机扫码即传
- 沉浸式：以《某科学的超电磁炮》「妹妹网络」为美学骨架

**视觉方向**：和风海报美学（钴蓝背景 + 立绘 + 字标 + 白卡片）。详见 [01-design-system.md](01-design-system.md)。**不**走赛博暗黑终端。

## 信息架构

```
顶部导航：[首页 HOME] [网络 NETWORK] [ACGN]   + 状态灯 + 设置

首页 HOME       登录卡（手动 / QR 接入）+ 统计仪表盘 + 活动流
网络 NETWORK    节点雷达 / 传输信道 / 任务面板（登录后核心页）
ACGN            世界观 + 角色档案 + 彩蛋 + 致敬声明
设置（弹出）    TURN / 主题 / 音效 / 黑名单 / 语言
```

## 技术栈

| 模块 | 选型 |
|---|---|
| 前端 | React 18 + TypeScript + Vite + Tailwind |
| 状态 | Zustand |
| 路由 | React Router v6 |
| P2P | WebRTC DataChannel（原生） |
| QR | `qrcode` 生成 / BarcodeDetector + jsQR 降级 |
| 本地存储 | IndexedDB (`idb`) |
| 信令 | Node.js + `ws` 单文件 |
| 部署 | 前端 GitHub Pages；信令 Railway / 自托管 |

## 核心交互流程

**PC 登录 → 手机扫码加入**
```
PC 自动生成「御坂10032号 + 485291」→ 右上 QR
手机扫码 → 自动跳转 → 自动填通行码 → 接入 → 出现在 PC 雷达
```

**文件传输**
```
选中节点 → 拖入文件 → 对端「检测到数据包传入」确认
→ WebRTC DataChannel 直传，优先 host candidate
```

**断网重连**
```
传输中断 → IndexedDB 保留已完成 chunk 列表
→ 重连后接收方上报「已收到 0~847」
→ 发送方从 848 续传
```

## 关键约束

- TURN 默认禁用（用户在设置中手动配）
- 服务器只做信令，永不存储文件
- 通行码错误 3 次锁定 5 分钟
- 30 分钟会话保留（断线后 30min 内可恢复）
- 节点编号 1~20001（致敬原著妹妹数量）
- Fan-made 非商业，致敬镰池和马、冬川基

## MVP 迭代

- **v1 核心**：身份 + 首页 + 信令 + PC↔PC WebRTC + 任务面板 + ACGN 静态页
- **v2 移动 + 容错**：三类 QR 扫码 + 移动端适配 + 断点续传 + TURN 自配置
- **v3 完善**：节点雷达可视化 + 传输历史 + PWA + 主题 + 彩蛋
