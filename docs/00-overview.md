# 00 · 总览

## 产品定位

**御坂网络（Misaka Network）** — 浏览器内 P2P 文件传输 Web APP。

- 零注册：节点编号（御坂XXX号）+ 6 位通行码即用
- 端到端加密：WebRTC DataChannel 上 AES-GCM 分片；**信令服务器永不存储文件内容**
- 跨设备：PC ↔ 手机扫码即传
- 沉浸式：以《某科学的超电磁炮》「妹妹网络」为美学骨架

**直连 vs 中继（请区分两件事）：**

| 说法 | 实际含义 |
|------|----------|
| 文件本体不经服务器存储 | ✅ 信令进程从不落盘文件字节 |
| 流量永不经过第三方 | ❌ 不成立：NAT 打洞失败时，**端到端加密流**可经 TURN 中继（Cloudflare 或用户自配）；中继方仍无法解密应用层密文 |

当直连成功时路径是端到端直传；当失败时加密流可能被中继——「不可读内容」≠「流量从不接触第三方」。

**视觉方向**：和风海报美学（钴蓝背景 + 立绘 + 字标 + 白卡片）。详见 [archive/01-design-system.md](archive/01-design-system.md)。**不**走赛博暗黑终端。

## 信息架构

```
顶部导航：[首页 HOME] [网络 NETWORK] [ACGN]   + 状态灯 + 设置

首页 HOME       登录卡（手动 / 节点 QR 接入）+ 统计仪表盘 + 活动流
网络 NETWORK    节点雷达 / 传输信道 / 任务面板（登录后核心页）
ACGN            世界观 + 角色档案 + 彩蛋 + 致敬声明
设置（弹出）    中继 / 音效 / 关于
```

| 模块 | 选型 |

## 核心交互流程

**PC 登录 → 手机扫码加入**
```
PC 自动生成「御坂10032号 + 485291」→ 右上 节点 QR
手机扫码 → 自动跳转 → 单独输入通行码 → 兑换一次性 admission grant → 接入 → 出现在 PC 雷达
```

**文件传输**
```
选中节点 → 拖入文件 → 对端确认
→ WebRTC DataChannel，优先 host candidate；失败时可走 TURN 中继（密文）
```

**断网重连**
```
传输中断 → 本地存储保留已完成 chunk bitmap
→ 重连后接收方上报缺失范围
→ 发送方续传 / 修复
```

## 关键约束

- TURN 默认由服务端策略与用户设置共同控制（设置页「中继」）
- 信令服务器只做身份 / 信令 / 统计 / TURN 签发；**永不存储文件内容**
- 通行码错误 3 次锁定 5 分钟
- 30 分钟会话保留（断线后 30min 内可恢复）
- 节点编号 1~20001（致敬原著妹妹数量）
- Fan-made 非商业，致敬镰池和马、冬川基

## MVP 迭代（已交付摘要）

- **v1 核心**：身份 + 首页 + 信令 + PC↔PC WebRTC + 任务面板 + ACGN 静态页
- **v2 移动 + 容错**：节点 QR 扫码接入 + 移动端适配 + 断点续传 + TURN（自动/手动）
- **v3 完善**：节点雷达可视化 + 传输历史 + PWA + 音效 + 彩蛋
