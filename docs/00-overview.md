# 00 · 总览

## 产品定位

**御坂网络（Misaka Network）** 是一个浏览器内运行的 P2P 文件传输 Web APP。

**核心特点：**
- 零注册：节点编号（如「御坂10032号」）+ 6 位通行码即可使用
- 端到端：文件本体走 WebRTC P2P，不经服务器
- 跨设备：PC ↔ 手机扫码即传
- 沉浸式：UI/文案以《某科学的超电磁炮》「妹妹网络」为骨架

## 信息架构

```
顶部导航：[首页 HOME] [网络 NETWORK] [ACGN]

首页 HOME
  ├─ 登录卡片（节点编号 + 通行码）
  ├─ 网络运行情报（统计仪表盘）
  └─ 实时活动流

网络 NETWORK（登录后核心页）
  ├─ 节点雷达（左 1/3）
  ├─ 传输 Channel（中 1/3）
  └─ 传输面板（右 1/3）

ACGN
  ├─ 世界观介绍
  ├─ 角色档案
  ├─ 致敬声明
  └─ 彩蛋功能

设置（用户菜单弹出）
  ├─ TURN 服务器配置
  ├─ 主题切换
  ├─ 音效开关
  ├─ 黑名单管理
  └─ 语言切换
```

## 核心交互流程

### 流程 1：PC 端登录 → 手机端扫码加入
```
1. 用户在 PC 打开 misaka.network
2. 自动生成「御坂10032号 + 485291」
3. 页面右上角显示 QR
4. 手机扫码 → 自动跳转 → 自动填入通行码 → 接入网络
5. 手机端自动出现在 PC 的「节点雷达」
```

### 流程 2：文件传输
```
1. PC 端选择「御坂10032号」节点
2. 拖入文件
3. 手机端弹出「检测到数据包传入」确认
4. 接收 → WebRTC DataChannel 直传
5. 优先走局域网 host candidate，自动选择最快路径
```

### 流程 3：断网重连
```
1. 传输中断，本地保留已完成 chunk 列表（IndexedDB）
2. 网络恢复后重连
3. 接收方上报「已收到 chunk 0~847」
4. 发送方从 chunk 848 续传
```

## 关键约束

- **TURN 默认禁用**：用户需在设置中手动填写自己的 TURN 服务器
- **服务器只做信令**：永不存储文件
- **通行码强制**：进入 Channel 必须验证通行码，错误 3 次锁定 5 分钟
- **30 分钟会话保留**：用户退出后 30 分钟内编号 + 通行码组合保留
- **节点编号范围 1~20001**：致敬原著妹妹数量
