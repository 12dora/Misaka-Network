## 1. 关于御坂网络

文案模板（可由编码 AI 润色）：

> **御坂网络** 是连接全部御坂妹妹的脑量子波共享网络。
>
> 在《某科学的超电磁炮》设定中，约 20,000 名御坂妹妹（实验体）通过脑量子波互联，形成分布式意识网络。每个妹妹既是独立个体，又能共享视觉、记忆、知识。
>
> 本 APP 借用这一设定作为美学骨架，构建一个 P2P 文件传输工具：每位用户都是一个「节点」，节点之间通过加密信道直接共享数据。

## 2. 实验体档案

卡片网格，每个角色一张卡：

- **御坂美琴**（原型）
  - 称号：电击使、超电磁炮
  - 学园都市第三位 LV5 超能力者
  - 御坂妹妹的 DNA 提供者

- **御坂 10032 号**
  - 称号：青蛙玩偶持有者
  - 御坂妹妹中最为人熟知的个体
  - 「这种事情，御坂如此问道」

- **Last Order（御坂 20001 号）**
  - 称号：管制人格、网络管理者
  - 御坂网络的核心节点
  - 「咪萨咖咪萨咖～」

- **打止（Last Order）的设定细节**
  - 出现新用户接入时，可显示「检测到新实验体，最新编号已更新」

## 3. 彩蛋功能

### 妹妹语录生成器
随机生成「御坂如此说道」风格句子：
```
[ 生成语录 ]

御坂望着手中的青蛙玩偶——御坂如此报告道。
```

### 实验体编号查询
输入 1~20001，返回该编号的「设定」：
- 有原著记录的编号（9982、10031、10032、19090、20001 等）：显示真实设定
- 其他编号：随机生成一句符合人设的描述

### 网络日志（伪事件流）
显示一些伪造的「网络历史事件」：
```
[20XX/XX/XX] 御坂 10032 号首次进入第七学区
[20XX/XX/XX] 御坂网络连接数突破 10000
[20XX/XX/XX] 检测到管制人格接入
```
